# learn

A Claude Code skill that teaches a topic so it locks in and is understood, not memorized.

Obsidian-first: lessons, visuals, questions, and your written answers live in your vault; the terminal is just the control channel. Stateful across sessions - each topic gets a folder with a `Map.md` tracking the dependency graph, mastery status, and scaffold tier.

## Install

Copy `SKILL.md` into `~/.claude/skills/learn/SKILL.md`, then invoke with `/learn <topic>`.

Assumes a vault at `~/Obsidian Vault/` and sandboxes at `~/Learning/` - edit the paths in `SKILL.md` to match your setup.
